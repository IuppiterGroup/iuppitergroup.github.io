Vox Codex

Audiobook Creator — v1.0 • Windows

⬇ Download Vox Codex (.zip)

File: vox-codex-v1.zip
Extract the zip and run VoxCodex.exe to begin.

🖥️ Windows Only • Internet connection required

Getting Started

  1. Download and extract the zip file
  2. Run VoxCodex.exe — the program takes a moment to initialize on first launch
  3. Click Open PDF and choose your document; chapters are detected automatically
  4. Review or edit the chapters, pick a voice, and adjust rate and pitch
  5. Click Preview to sample, then Generate All to save an MP3 per chapter plus a combined Full Audiobook file
